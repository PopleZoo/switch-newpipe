# Testing Checklist

## 목적

이 문서는 실기에서 무엇을 확인해야 하는지 빠르게 체크하기 위한 목록이다. 문제 발생 시 로그는 `sdmc:/switch/switch_newpipe.log`를 본다.

## 지금까지 구현된 것

- 실제 YouTube 홈 / 검색 / 구독 / 상세 / 채널 / 연관 추천
- 로그인 기반 추천 홈 1차 연결
- watch-next 기반 연관 영상 파서
- 재생목록 / 댓글 파서
- 외부 쿠키 import 기반 로그인 세션 저장
- 최근 시청 / 즐겨찾기 저장
- Switch 전용 mpv 플레이어 루프
- 재생 로딩 오버레이와 상태 문구
- 설정 저장
  - 시작 탭
  - 기본 홈 카테고리
  - 재생 품질 정책
  - 짧은 영상 숨기기

## 테스트 전 준비

- 최신 `switch_newpipe.nro` 배포 여부 확인
- 로그인 테스트가 필요하면 `switch_newpipe_auth.txt`를 `sdmc:/switch/`에 배치
- 이전 로그가 헷갈리면 `switch_newpipe.log`를 지우고 시작

## 부팅 / 기본 동작

- 앱이 부팅 직후 튕기지 않는지
- 홈 / 검색 / 구독 / 라이브러리 / 설정 탭이 모두 보이는지
- 탭 이동과 포커스 이동이 끊기지 않는지
- 목록에서 `Y` 상세 화면이 정상 표시되는지

## 사이드바 포커스 상태 탭 액션 (issue #3)

탭 액션은 이제 탭 본문과 사이드바 항목 양쪽에 등록된다. 아래는 사이드바 항목에
포커스가 있는 상태, 즉 아직 본문으로 포커스를 옮기지 않은 상태에서 확인한다.

- 검색 탭 사이드바에서 `X`를 누르면 소프트 키보드가 뜨는지
  - 검색 결과가 하나도 없는 첫 진입 상태에서도 뜨는지
- 하단 힌트 줄에 `X 검색`이 실제로 표시되는지
- 홈 탭 사이드바에서 `X` 새로고침 / `Y` 카테고리 순환이 되는지
- 구독 탭 사이드바에서 `X` 새로고침 / `RB` 세션 관리가 되는지
  - 로그아웃 상태, 즉 카드가 없는 상태에서도 되는지
- 라이브러리 탭 사이드바에서 `X` 새로고침 / `LB` 섹션 전환이 되는지
  - 최근 시청 기록이 비어 있는 상태에서도 되는지
- 라이브러리 `RB` 비우기는 본문 카드에 포커스가 있을 때만 동작하는지
  - 사이드바에서 실수로 눌러 기록이 지워지지 않아야 한다

## 포커스 소실 회귀

포커스를 잃으면 방향키 이동이 전부 죽어서 앱을 재실행해야 한다. 아래를 확인한다.

- 홈에서 카드에 포커스를 둔 상태로 `X` 새로고침을 눌렀을 때
  - 목록이 갱신되고 하이라이트가 사이드바로 돌아오는지
  - 방향키 이동이 계속 되는지, 먹통이 되면 회귀다
- 구독 카드에 포커스를 둔 상태로 `X` 새로고침 반복
- 라이브러리 카드에 포커스를 둔 상태로 `LB` 섹션 전환 반복
- 검색 결과가 없는 상태의 검색 탭 사이드바에서 `A`를 눌렀을 때
  - 하이라이트가 사이드바에 그대로 남아 있는지
  - 이후 위아래 탭 이동이 계속 되는지
- 로그아웃 상태 구독 탭, 비어 있는 라이브러리 탭에서도 같은지

## 라벨 줄간격 / 카드 그리드 레이아웃 (issue #4)

`lineHeight`는 px가 아니라 fontSize 배수다. 아래 화면에서 본문 라벨이 화면을
독차지하지 않고 카드 그리드가 정상적으로 보이는지 확인한다.

- 구독 탭 로그인 상태에서 상태 문구 바로 아래에 카드 그리드가 보이는지
  - 카드가 화면 밖으로 밀려나 빈 화면처럼 보이면 회귀다
- 구독 탭 로그아웃 상태 안내 문구가 화면을 넘기지 않는지
- 구독 카드에서 `A` 재생 / `Y` 상세가 되는지
- 라이브러리 탭 본문 문구 아래 카드 그리드가 보이는지
- 상세 화면 설명 본문이 한 줄씩 화면을 채우지 않고 정상 줄간격으로 보이는지

## 홈 / 검색

- 홈 탭에서 카드 목록이 실제 유튜브 데이터로 보이는지
- 로그인 세션이 있을 때 `추천` 탭이 개인화 feed 느낌으로 바뀌는지
- `Y`로 홈 카테고리 순환이 되는지
- `X` 새로고침이 정상인지
- 검색 탭에서 아무 키워드나 넣었을 때 결과가 나오는지
- 짧은 영상 숨기기 설정을 켠 뒤 홈 / 검색 결과가 달라지는지

## 상세 / 채널 / 연관

- 목록에서 `Y`로 상세 화면이 열리는지
- 상세에서 설명 / 메타데이터가 보이는지
- 상세에서 `X` 채널 업로드가 열리는지
- 상세에서 `Y` 연관 추천이 열리는지
- 상세에서 `LB` 메뉴가 뜨는지
- 상세에서 `LB -> 재생목록`이 열리는지
- 상세에서 `LB -> 댓글`이 열리는지
- 연관 추천이 단순 검색 느낌이 아니라 실제 watch-next 느낌의 목록인지

## 재생

- 목록에서 `A`로 바로 재생되는지
- 로딩 progress circle과 상태 문구가 보이는지
- 재생 후 `A` pause / resume 동작이 맞는지
- `B`로 플레이어 종료 후 앱으로 복귀하는지
- `위 / 아래` 볼륨이 동작하는지
- 첫 재생 직후 OSD가 자동으로 잠깐 보이는지
- `A` pause / resume 때 OSD 상태 문구가 바뀌는지
- `위 / 아래` 볼륨 조절 시 OSD 볼륨 바가 반응하는지
- `X` 또는 `Y`로 OSD 고정 표시 토글이 되는지
- 긴 영상에서 초반 몇 초 뒤 멈추거나 fatal error가 없는지

## 시간 이동 (seek)

`좌 / 우` 10초, `LB / RB` 60초다. 경로별로 허용 범위가 다르니 어떤 경로였는지 함께
기록한다. OSD 품질 라벨과 로그의 `player: seek` 줄을 보면 된다.

- 720p HLS 경로에서
  - 뒤로 이동 후 계속 재생되는지
  - 앞으로 이동이 버퍼 제한 없이 되는지
  - 여러 번 연속으로 눌렀을 때 OSD 시간이 누적되어 표시되는지
- progressive / UMP 브리지 경로에서
  - 이미 지나온 구간으로 뒤로 이동이 되는지
  - 아직 안 받은 구간으로 앞으로 이동하면 OSD에 `BUFFERED TO mm:ss`가 뜨고
    재생이 끊기지 않는지
  - 앞으로 이동이 막힌 뒤에도 다운로드가 계속 진행되는지
  - 오디오가 분리된 720p에서 이동 후 영상과 소리가 계속 맞는지
- 진행 바에 버퍼 구간이 밝은 회색으로 보이는지, 다운로드가 진행되며 늘어나는지
- 라이브 스트림에서 이동을 시도하면 `LIVE STREAM NO SEEK`가 뜨는지
- 로딩 중에 좌우를 눌러도 무시되는지
- 이동 직후 OSD 시간이 뒤로 튀지 않는지
- **회귀 확인**: seek을 전혀 누르지 않은 재생이 이전과 동일하게 끝까지 되는지
  - 특히 720p UMP 경로. 여기서 깨지면 `stream_open`의 `seek_fn`을 `nullptr`로
    돌리면 이전 동작으로 복귀한다

## 재생 품질 설정

- 설정 탭에서 `재생 품질` 변경 가능 여부
- `표준 720p`에서 재생 성공 여부
- `호환성 우선`에서 재생 성공 여부
- `데이터 절약`에서 재생 성공 여부
- 설정을 바꾼 뒤 체감 화질이나 로딩 특성이 달라지는지

## 720p tokenless Android VR / UMP 실기 검증

2026-07-17 `ruzSopZIFKc` 실기 시험에서 720p video 71,936,808 B와 AAC audio
8,565,660 B 전체 다운로드 및 재생을 확인했다. 아래 항목은 회귀 시험 체크리스트다.

- HLS가 없는 `bsRH-6Zmsjk`를 `표준 720p`로 실행했는지
- 로딩 중 `GENERATING PLAYBACK TOKEN` 없이 `REQUESTING 720P UMP STREAM`으로 넘어가는지
- OSD 품질이 `720P AVC UMP`인지
- 1:04 이후에도 영상과 음성이 계속 재생되는지
- 끝까지 재생하거나 로그의 UMP 다운로드가 `clen`까지 도달하는지
- 실패 시 360p progressive로 자동 전환되어 재생 자체는 계속되는지
- 로그에 다음 흐름이 있는지
  - `youtube: selected tokenless Android VR UMP`
  - `player: using tokenless Android VR UMP ranged download`
- 실패하면 `youtube: UMP`, `player: UMP`가 포함된 로그 줄을 함께 보관할 것

## 설정 persistence

- 설정 탭에서 `시작 탭` 변경 후 앱 재실행 시 반영되는지
- `기본 홈 카테고리` 변경 후 홈 첫 진입이 바뀌는지
- `짧은 영상 숨기기` 변경 후 재실행 뒤에도 유지되는지
- `X` 기본값 복원이 동작하는지
- `sdmc:/switch/switch_newpipe_settings.json` 파일이 생성되는지

## 로그인 / 구독

- `switch_newpipe_auth.txt` import가 되는지
- 구독 탭에서 로그인 세션 상태가 보이는지
- 구독 목록이 실제 계정 기준으로 뜨는지
- 구독 목록에서도 `A` 재생, `Y` 상세가 되는지
- 앱 재실행 후 저장된 세션이 유지되는지
- 홈 `추천` 탭도 로그인 반영 상태로 바뀌는지

## 라이브러리

- 재생한 영상이 최근 시청에 쌓이는지
- 상세에서 `RB` 즐겨찾기 토글이 되는지
- 라이브러리에서 최근 시청 / 즐겨찾기 전환이 되는지
- `RB`로 현재 섹션 비우기가 동작하는지
- `sdmc:/switch/switch_newpipe_library.json` 파일이 생성되는지

## 문제 발생 시 기록할 것

- 어떤 탭 / 어떤 버튼 / 어떤 영상에서 문제였는지
- 재생 품질 설정이 무엇이었는지
- 로그인 세션 사용 중이었는지
- 로그 마지막 20~50줄
- 가능하면 재현 절차를 짧게 3줄 이내로 정리
